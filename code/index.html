Quant Code Snippets

Vectorised, tested Python reference implementations of quantitative finance measures. Each snippet is tested before publication and re-executed by the generator on every rebuild, is MIT licensed, and links to the definition and formula it implements.

Numba Rolling Operators

O(n) rolling mean, standard deviation, OLS beta and 2-D z-score compiled with Numba. In tests here they run 4 to 7 times faster than pandas and are more accurate on large-valued series.

rolling-window-numba.py · explanation and tests

Data Engineering for Quantsduckdb

DuckDB + Parquet Ticks

Build 1-minute OHLCV and VWAP bars, and daily turnover, straight from Hive-partitioned tick Parquet files with DuckDB. There is no database server and no loading step, and filters skip unneeded files and row groups.

duckdb-parquet-ticks.py · explanation and tests

Backtestingnumpy, pandas, polars

Vectorised Backtest

A daily long-only backtest core that vectorises over the whole stock universe. It blocks look-ahead by construction and handles suspensions, limit-up and limit-down untradability and turnover costs. A Polars version is included for the unconstrained case.

vectorized-backtest.py · explanation and tests

High-Performance Pythonnumpy

Cython Rolling Mean

The expanding-then-fixed rolling mean from a boundscheck-free Cython memoryview loop, implemented here with a NumPy prefix sum so the generator can re-execute it. The Cython source is included for compilation on a machine with a C toolchain.

cython-rolling-mean.py · explanation and tests

DuckDB Parquet Loader

Read a date slice of tick Parquet through DuckDB. The file glob and the date are bound parameters, so a path or a date string cannot change the SQL.

duckdb-parquet-loader.py · explanation and tests

Polars MA Backtest

A moving-average crossover in Polars lazy expressions. The position is shifted one bar so it cannot earn the return that formed the signal, and a cost is charged when the position changes. Educational example only.

polars-vectorized-backtest.py · explanation and tests

Exponentially weighted variance compiled with Numba. The variance at t uses returns only through t−1, so the latest shock is not included in the volatility assigned to that same index.

pandas-tick-to-ohlcv.py · explanation and tests

Data Engineering for Quantsnumpy, pandas

Volume Bars

Group trades into bars that each contain about the same traded volume. The trade that crosses the threshold stays in the bar it completes. A single trade larger than the threshold is not split.

pandas-volume-bars.py · explanation and tests

Time Series & Stat-Arbpandas

Pair Z-Score

A rolling OLS hedge ratio between two price series, the spread y − βx, and a rolling z-score of that spread. The z-score uses a second window on an already rolling spread, so it is defined later than β. Illustrative only; not a trading signal.

pairs-zscore-signal.py · explanation and tests

High-Performance Pythonnumpy

NumPy Strided Rolling

Build each rolling window as a view with sliding_window_view and reduce it in NumPy. The view shares memory with the input. Sample standard deviation of zero becomes a missing z-score, not an infinity.

numpy-strided-rolling.py · explanation and tests

High-Performance Pythonnumpy, numba

Numba Book Imbalance

Walk a tape of best-bid and best-ask sizes in a compiled loop and emit the queue imbalance at each update. A locked or empty touch, where the two sizes sum to zero, is recorded as zero rather than as a division by zero.

numba-order-book-replay.py · explanation and tests

Polars As-Of Quotes

Backward as-of join, per symbol, from trades to the latest quote at or before the trade. Trade side is then +1 above the mid, −1 below it, 0 at the mid, and missing when no quote has printed yet.

polars-asof-join-quotes.py · explanation and tests

Execution & Market Microstructurenumpy, pandas

VWAP in Python

The ratio of cumulative traded value to cumulative volume over a horizon. The standard benchmark for judging institutional execution quality.

vwap.py · definition and formula

HFT & Order Book Dynamicsnumpy, pandas

OFI in Python

Net buy-minus-sell pressure at the best bid and ask, measured from changes in top-of-book prices and sizes. Short-horizon price changes are approximately linear in OFI.

ofi.py · definition and formula

Time Series & Stat-Arbnumpy

Hurst Exponent in Python

A scaling exponent that measures long-range dependence in a time series. H < 0.5 indicates mean reversion, H = 0.5 a random walk, and H > 0.5 a persistent, trending series.

hurst-exponent.py · definition and formula

Factor Research & Alpha Evaluationnumpy, pandas

Information Coefficient in Python

The cross-sectional correlation between a factor's values and subsequent asset returns. Rank IC, its mean and ICIR are the standard first test of whether an alpha factor predicts returns.

information-coefficient.py · definition and formula

Time Series & Stat-Arbnumpy, statsmodels

ADF Test in Python

A unit-root test that checks whether a time series is non-stationary. In stat-arb it is the standard check that a spread mean-reverts before it is traded.

adf-test.py · definition and formula

Time Series & Stat-Arbnumpy, statsmodels

Cointegration in Python

Two or more non-stationary price series are cointegrated when some linear combination of them is stationary. This is the statistical basis of pairs and basket trading.

cointegration.py · definition and formula

Risk Managementnumpy, scipy

VaR & ES in Python

VaR is the loss threshold that is exceeded only with a given small probability. Expected Shortfall is the average loss in that tail. Both are standard risk limits; ES is what Basel FRTB uses for market risk capital.

var-expected-shortfall.py · definition and formula

Execution & Market Microstructurenumpy, pandas

Amihud Illiquidity in Python

The average absolute return per unit of traded value: how much the price moves for each yuan or dollar traded. It is a low-frequency price-impact proxy and a widely used liquidity factor.

amihud-illiquidity.py · definition and formula

Market Microstructure & Order Flownumpy, pandas

VPIN in Python

An estimate of order-flow toxicity from the imbalance between buy and sell volume inside equal-volume buckets. It updates by volume, not by the clock.

vpin.py · definition and formula

Execution & Market Microstructurepandas

TWAP in Python

The arithmetic average of prices sampled on a regular clock. As a benchmark every interval counts once; as a schedule, a parent order is sliced evenly in time.

twap.py · definition and formula

Execution & Transaction Cost Analysisstandard library

Implementation Shortfall in Python

The gap between a paper portfolio filled at the decision price and the portfolio that was actually traded, including fees and the cost of shares that never got filled.

implementation-shortfall.py · definition and formula

Execution & Transaction Cost Analysisstandard library

Arrival Price in Python

Execution cost against the mid-price at the moment the order arrived, in basis points. Positive means the fills were worse than that mid.

arrival-price.py · definition and formula

Execution & Market Microstructurestandard library

Participation Rate in Python

The fraction of market volume an order takes over an interval. A percent-of-volume schedule sets each child order to that fraction of the volume just observed, capped by what is left.

participation-rate.py · definition and formula

Execution & Market Impactnumpy

Almgren-Chriss in Python

A deterministic schedule that liquidates a position by a fixed horizon, trading off temporary market impact against the variance of the remaining inventory. This page uses the continuous-time trajectory with permanent impact set to zero.

almgren-chriss.py · definition and formula

Market Microstructure & Order Flownumpy

Kyle's Lambda in Python

The slope of price changes on signed order flow. A larger lambda means the same signed volume moves the price more, which is the usual reduced-form reading of a less liquid market.

kyles-lambda.py · definition and formula

Market Microstructure & Order Flowstandard library

PIN in Python

The share of trading that the Easley-Kiefer-O'Hara-Paperman model attributes to informed traders, given the chance of an information event and the arrival rates of informed and uninformed orders.

pin-informed-trading.py · definition and formula

Performance & Risk Metricsnumpy

Sharpe Ratio in Python

Mean excess return divided by the standard deviation of excess return, annualised by the square root of the number of periods per year. The same definition as the performance calculator on this site.

sharpe-ratio.py · definition and formula

Performance & Risk Metricsnumpy

Sortino Ratio in Python

Mean return above a minimum acceptable return, divided by downside deviation and annualised. Upside variation does not enter the denominator.

sortino-ratio.py · definition and formula

Performance & Risk Metricsnumpy

Information Ratio in Python

Mean active return versus a benchmark, divided by the tracking error of that active return, and annualised. It scores how large and how steady the gap versus the benchmark was.

information-ratio.py · definition and formula

Performance & Risk Metricsnumpy

Tracking Error in Python

The annualised sample standard deviation of portfolio return minus benchmark return. It measures how far the two series wandered from each other, not whether one ended ahead.

tracking-error.py · definition and formula

Performance & Risk Metricsnumpy

Max Drawdown in Python

The most negative peak-to-trough decline of an equity curve. A 25 percent decline is returned as −0.25, not as 0.25.

max-drawdown.py · definition and formula

Performance & Risk Metricsnumpy

Calmar Ratio in Python

Compound annual growth of an equity curve divided by the absolute value of its maximum drawdown. This implementation uses the whole sample, not a trailing 36-month window.

calmar-ratio.py · definition and formula

Position Sizingstandard library

Kelly Criterion in Python

The bet size that maximises expected logarithmic growth. For a binary bet it is an exact fraction of wealth. For a continuous return it is approximately mean over variance. It is a sizing formula, not advice to use it.

kelly-criterion.py · definition and formula

Portfolio & Factor Modelsnumpy

Beta in Python

The OLS slope of an asset's returns on a market's returns: covariance divided by the market's variance. It is the CAPM coefficient on the sample you pass in, not a forecast.

beta.py · definition and formula

Volatility Modelingnumpy

Realized Volatility in Python

The square root of the sum of squared log returns inside one window, optionally scaled to a year. For a single day of intraday prices, multiplying by 252 annualises that day's realized variance. Do not do that to a stack of many days.

realized-volatility.py · definition and formula

Volatility Modelingnumpy

Parkinson Volatility in Python

A volatility estimator that uses each period's high and low instead of the close-to-close move. Under a driftless Brownian motion it is more efficient than the close-to-close estimator. With drift, jumps or a close that is not the whole story, that efficiency result does not apply.

parkinson-volatility.py · definition and formula

Volatility Modelingnumpy

GARCH(1,1) in Python

A conditional variance that is a constant plus a weight on yesterday's squared shock plus a weight on yesterday's variance. This page filters a series with given parameters. It does not estimate them.

garch.py · definition and formula

Options & Derivativesscipy

Implied Volatility in Python

The volatility that makes a Black-Scholes-Merton price match an observed option premium. It is solved numerically. There is no closed form for the call price inverted in volatility.

implied-volatility.py · definition and formula

Options & Derivativesscipy

Delta in Python

The derivative of a European option's Black-Scholes-Merton value with respect to the spot. A call delta is e^{−qT} N(d1). A put delta is that quantity minus e^{−qT}.

delta.py · definition and formula

Options & Derivativesscipy

Gamma in Python

The second derivative of a European option's value with respect to the spot, and the derivative of delta. In Black-Scholes-Merton the call and the put of the same strike and expiry have the same gamma.

gamma.py · definition and formula

Options & Derivativesscipy

Vega in Python

The sensitivity of a European option's Black-Scholes-Merton value to volatility, quoted per volatility point (one percentage point of σ). Call and put vegas of the same contract are equal.

vega.py · definition and formula

Options & Derivativesscipy

Theta in Python

The sensitivity of a European option's Black-Scholes-Merton value to the passage of calendar time, quoted per day. The annual derivative is divided by 365.

theta.py · definition and formula

Options & Derivativesscipy

Rho in Python

The sensitivity of a European option's Black-Scholes-Merton value to the continuous risk-free rate, quoted per one percentage point of rate.

rho.py · definition and formula

Options & Derivativesstandard library

Put-Call Parity in Python

A model-free relation between European call and put prices that share a strike and an expiry. With a continuous dividend yield, the call minus the put equals the prepaid forward minus the discounted strike.

put-call-parity.py · definition and formula

Time Series & Stat-Arbnumpy

Half-Life in Python

How many periods an AR(1) deviation takes to decay halfway, read off the slope of a regression of changes on lagged levels. The same discrete definition as the half-life on the ADF page.

half-life-mean-reversion.py · definition and formula
