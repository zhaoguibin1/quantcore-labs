Formulas & Conventions

Expected Return: R_p = ∑ (w_i * R_i) Portfolio Risk: σ_p = √( w^T * Σ * w ) Sharpe Ratio: S = (R_p - R_f) / σ_p

$\Sigma$ represents the covariance matrix constructed using asset standard deviations and an assumed correlation coefficient ($\rho = 0.3$). Weights satisfy $\sum w_i = 1$ and $w_i \ge 0$ (no short-selling).

Frequently Asked Questions

Why does diversification reduce portfolio risk?
When assets are not perfectly correlated ($\rho < 1$), combining them smooths out independent return fluctuations, reducing overall portfolio variance below the weighted average of individual variances.
How is the covariance matrix determined in this calculator?
Covariances are computed as $\Sigma_{ij} = \sigma_i \sigma_j \rho_{ij}$, assuming a moderate cross-asset correlation coefficient ($\rho = 0.3$) for illustrative multi-asset diversification.
