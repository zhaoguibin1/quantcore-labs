Formulas & Conventions

Expected return: R_p = Σ w_i·μ_i Portfolio risk: σ_p = √( wᵀ Σ w ), Σ_ij = σ_i σ_j ρ_ij Sharpe ratio: S = (R_p − R_f) / σ_p Constraints: w_i ≥ 0, Σ w_i = 1 (long-only, fully invested) Max Sharpe (exact): for every subset A of assets solve Σ_A z = μ_A − R_f; keep solutions with all z > 0, normalise w = z / Σz, take the best. Frontier (exact): for target R, {Σw = 1, μ·w = R, w ≥ 0} is a segment w₀ + t·d; minimise the quadratic σ²(t) on it in closed form. CML: R = R_f + S* · σ through the max-Sharpe portfolio

Σ is built from the volatilities and the three pairwise correlations you enter, and must be positive definite (the page rejects impossible combinations such as ρ₁₂ = 0.9, ρ₂₃ = 0.9, ρ₁₃ = −0.9). The optimum does not depend on the random portfolios, which are drawn uniformly over all weight combinations (Dirichlet(1,1,1)) only to show the feasible region.

Frequently Asked Questions

Why does diversification reduce portfolio risk?
When assets are not perfectly correlated (ρ < 1), combining them smooths out independent return fluctuations, so portfolio volatility falls below the weighted average of the individual volatilities.
How is the covariance matrix determined in this calculator?
Covariances are Σ_ij = σ_i σ_j ρ_ij from the volatilities and the three correlations you enter (default 0.3). The matrix must be positive definite; otherwise the correlations are mutually impossible and the page asks you to change them.
Is the maximum Sharpe portfolio found by random sampling?
No. It is computed exactly by enumerating which assets hold positive weight and solving the tangency equations on each subset, so it does not depend on the number of random portfolios. The random portfolios only visualise the feasible region.
