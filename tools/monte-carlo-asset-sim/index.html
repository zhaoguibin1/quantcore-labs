Formulas & Conventions

S_t = S_0 * exp( (μ - 0.5 * σ²) * t + σ * W_t ) ΔS_t = S_t * exp( (μ - 0.5 * σ²) * Δt + σ * √(Δt) * Z_i ) where Z_i ~ N(0, 1)

$Z_i$ is sampled using the Box-Muller transformation ($Z = \sqrt{-2\ln u_1} \cos(2\pi u_2)$). The discrete-time solution prevents log-drift bias and matches exact log-normal terminal distributions.

## Mathematical Assumptions

  • Exact log-normal transition probabilities: S(t+Δt) = S(t) * exp((μ - 0.5*σ²)*Δt + σ*sqrt(Δt)*Z)
  • Independent increments; constant drift μ and volatility σ across all step intervals.

Frequently Asked Questions

Why does the formula use (μ - 0.5 * σ²) instead of just μ?
This term arises from Itô's Lemma. Because log-returns are normally distributed, the expectation of $e^{\sigma W_t}$ is $e^{0.5\sigma^2 t}$. Subtracting $0.5\sigma^2$ ensures that the expected asset price $\mathbb{E}[S_t]$ equals $S_0 e^{\mu t}$.
Can this simulator be used for path-dependent derivative pricing?
Yes. The simulated paths can be used directly to price Asian options (averaging path prices), Barrier options (checking knockout thresholds), or Lookback options by computing path statistics in real time.
